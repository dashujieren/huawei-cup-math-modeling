# 华为杯研究生数学建模团队仓库

本仓库用于统一管理比赛官方材料、数据、代码、实验结果、图表、论文和团队决策。远程仓库为 GitHub 私有仓库；未经团队确认，不向公开位置同步内容。

## 当前状态

- 仓库骨架已建立。
- 尚未导入当届官方题面、附件或提交规则。
- 尚未选择赛题、模型或论文方案。

## 目录导航

| 路径 | 用途 |
|---|---|
| `problem/official/` | 官方题面、附件、模板和提交规则；原文件只读保存 |
| `data/` | 原始数据、处理中间数据和最终建模输入 |
| `src/` | 可复现的数据处理、模型、验证与制图代码 |
| `scripts/` | 一键运行或批处理入口 |
| `configs/` | 参数、随机种子和路径配置 |
| `notebooks/` | 探索性分析，不作为最终结论的唯一来源 |
| `tests/` | 数据、约束、模型和结果检查 |
| `outputs/` | 带运行标识的实验结果和论文表格 |
| `figures/` | 最终论文图表 |
| `paper/` | 论文源文件及其素材 |
| `references/` | 团队获准保存的参考资料和检索记录 |
| `notes/` | 会议纪要与关键决策 |

## 开始协作

1. 从 GitHub 仓库页面的 **Code** 菜单复制地址并克隆。
2. 开始任务前同步 `main`，再创建短期分支：

   ```bash
   git switch main
   git pull --ff-only
   git switch -c model/baseline
   ```

3. 小步提交并推送分支，审阅后合并到 `main`。
4. 正式实验记录参数、随机种子、依赖版本和 Git 提交号。

完整约定见 [CONTRIBUTING.md](CONTRIBUTING.md)，已知比赛信息与材料状态见 [PROJECT_BRIEF.md](PROJECT_BRIEF.md)。

## 基本原则

- 不覆盖 `problem/official/` 和 `data/raw/` 中的原始文件。
- 不提交密码、令牌、队伍身份信息或私密个人数据。
- 正式结果必须能从已提交代码、配置和记录中追溯。
- 当届规则只以团队提供并核验的官方文件为准。
