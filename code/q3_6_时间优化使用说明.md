# 问题三方案六：时间优化统一入口

在 PyCharm 中运行 `q3_6.py`，工作目录设为这个 `code` 文件夹，“脚本形参”可留空。它调用同目录的 `q3_8_time_optimize.py` 求解与独立验收，默认输出到 `3_outputs/6_time/`。历史的 `q3_6_scheme2_equal_optimize.py` 是另一轮等权实验，保留原名和结果，不作为方案六入口。

默认从已验收的方案三少架次解开始，最晚返航目标为 7200 秒，正式搜索预算为 1200 秒；初始验收和出表出图另计。结束后看 `Q3_运行摘要.json`：`status=PASS` 表示运输、资源和连续通信验收通过；`target_reached` 表示是否找到 7200 秒内的可行解。未达到目标不等于证明原题不可行。

已取得的 8050.273 秒（2 小时 14 分 10 秒）正式结果仍保存在 `3_outputs/8_time/q3_time_260925_203114_673948_table/`。若要从这份已验收解继续搜索，在脚本形参中填写：

```text
--warm-table 3_outputs/8_time/q3_time_260925_203114_673948_table --grades G2
```

G2 将总能耗和加权软延期限制在原方案三少架次解的 110% 以内；硬截止、载荷、电池、中继实体和连续通信始终完整验收。需要 OR-Tools；若当前解释器缺少该库，在 `code` 目录运行 `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`，或选择已经安装依赖的 Python 环境。

师兄的方案五仍在求解。本入口只整合当前已验收的时间优化代码；收到方案五的 PASS 表后，应按同一数据清单和统一验收口径比较，再确定问题三最终采用哪一版。
