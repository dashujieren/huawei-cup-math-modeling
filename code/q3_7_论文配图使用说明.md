# 第三问方案三论文配图

在 PyCharm 中直接运行 `q3_7_paper_figures.py`。脚本只读取已保存且带 PASS/READY 验收标记的方案三结果，不运行求解器，也不改原始输出。需安装 `matplotlib`；当前项目虚拟环境已具备。

默认读取 `3_outputs/3_optimize/` 中唯一一轮 `*_sorties_table/Q3_方案比较.csv`，输出到同轮 `*_paper_figure/`。其中有两张 PDF（论文插图）、两张 PNG（预览），还保存 SVG、作图数据 CSV 和来源 JSON。若以后同目录出现多轮方案三结果，运行参数加 `--comparison-csv` 指定本次比较表；可用 `--output-dir` 自定新输出文件夹。

文件名带 `collision-audit` 或 `alignment` 的文件仅供版面核查，**不要作为论文插图**；论文使用没有这些后缀的两张正式 PDF。

四指标图的百分比为“本方案原始指标 ÷ 方案二原始指标 × 100%”，仅是可视化口径，并非方案三搜索的等权目标。权衡散点图未包含迟到指标，论文中应与四指标图或结果表一起解释。保存的验收记录为 PASS，但当前 `q3_1_optimize.py` 文件指纹与方案三运行记录不一致，不能把“图由 CSV 复现”写成“完整求解已复现”。
